Skypeek for AWS

Version 1.3.0

A read-only tray tool for everyday AWS lookups: health of Elastic Beanstalk, ECS, RDS, ElastiCache, EC2 and load balancers, logs, VPCs and security groups, secrets and parameters, and cost estimates.

The installer needs no administrator rights and keeps Skypeek up to date. The single file runs from anywhere and tells you when a new version is out.

Safe updates

  • Skypeek installs an update only if its release list is signed with the Skypeek release key, and each file matches the SHA-256 in that list.
  • The update check sends only the request for the release list, never data from your vault or AWS accounts.
  • You can turn automatic checks off in Settings → General.
  • The downloads aren't code-signed yet, so Windows SmartScreen may ask you to confirm the first start (More info → Run anyway).

Checksums

SHA-256 of every file: SHA256SUMS.txt. Release notes: latest release on GitHub.
